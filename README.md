# Yolo Test

## Install Python & PIP
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install python3-pip
python3 --version
pip3 --version
```

## Install Virtual ENV

```bash
sudo apt install python3.12-venv
python3 -m venv .venv
```

## Activate Virtual Environment

```bash
source .venv/bin/activate
```

## Install YOLO

```bash
# Instalamos YOLO
pip install ultralytics===8.3.27
```
